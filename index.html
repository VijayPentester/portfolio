Final-Year Project

ReconPipe

A Python CLI recon pipeline chaining eight tools into one repeatable workflow. Four-person team project — I own the Recon Engine module end to end.

Instead of running each recon tool by hand, ReconPipe chains them into a single pass: subdomain enumeration and dedup, live host detection, port scanning, endpoint discovery and crawling, parameter mining, and finally vulnerability scanning — with clean data handed off at every stage instead of noise.

Next up on the roadmap: an automatic risk score computed from Nuclei severity right after each scan, feeding into a consolidated report.
